# 経費メモ → 仕訳CSV 変換デモ

Excel や CSV の経費メモ（列名がばらばら・和暦・全角数字・¥付きの金額など）を、会計ソフトに取り込みやすい仕訳の形（取引日・借方勘定科目・借方金額・貸方勘定科目・貸方金額・摘要）に整えるデモです。

- 公開ページ: https://viefabri.github.io/keiri-shiwake-demo/
- データはブラウザの中だけで処理され、外部へは送信されません
- 判定できない行（勘定科目が分からない・日付が読めない・マイナス金額）は推測で埋めず「要確認」として残します
- サンプルの店名・金額は架空です。列の並び・文字コードは見本で、実際の会計ソフトの取込仕様に合わせて調整する前提です

作成: 生成AI（Claude Code）を使って要件整理・実装・テストを行いました。
